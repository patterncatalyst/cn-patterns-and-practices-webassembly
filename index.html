What this site is

A chapter-based, hands-on path to designing and deploying server-side WebAssembly components well, built around a single WIT world for a shipping and cargo domain. Every hands-on chapter ships the same example in both Rust (cargo-component, targeting wasm32-wasip2) and Go (standard Go: wasip1 plus go:wasmexport and the wasm-tools adapter, with TinyGo noted as the size-optimized alternative). The component serves HTTP via wasi-http and talks gRPC, runs on wasmtime and on wasmCloud unchanged, and deploys to Kubernetes on minikube (the containerd Wasm shim) and OpenShift Local. Later parts cover Kubernetes patterns (sidecar, ambassador/adapter, HPA scaling, scale-to-zero with KEDA), on-cluster observability with OTel and the Grafana LGTM stack, and then the deviations: Istio and WebAssembly (the WasmPlugin CRD), a survey of other Wasm backend architectures (serverless/FaaS with Spin), and portable inference with wasi-nn. Cross-reference the sibling REST and gRPC sites for the HTTP and gRPC protocol detail. It assumes you can read Rust and Go; it is not a tutorial in either language. All container images are UBI-based.
